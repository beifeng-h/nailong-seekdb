# 实测结果

本目录是统一基准的原始输出，由 `../bench/run_ab.sh` 生成。

| 文件 | 内容 |
| --- | --- |
| `result_baseline.json` | 基线实例（未打补丁的二进制）的完整结果 |
| `result_optimized.json` | 优化实例的完整结果 |
| `regress_baseline.tsv` | 基线的逐查询结果摘要（用于比对语义） |
| `regress_optimized.tsv` | 优化后的逐查询结果摘要 |
| `regress_*.tsv.topk` | 同上，只含 Top-10 检索的结果摘要 |
| `summary.txt` | 对比表（由 `compare_results.py` 生成） |

## 结果对比

100000 行语料、300 条查询、单线程，同一台机器（128 核 / 503 GB）：

| 阶段 | 指标 | 基线 | 优化后 | 变化 |
| --- | --- | ---: | ---: | ---: |
| 建索引 | 耗时 | 25.85 s | 21.53 s | -16.7% |
| 建索引 | 吞吐 | 3869 行/s | 4645 行/s | +20.1% |
| 带索引插入 | 耗时 | 41.40 s | 36.35 s | -12.2% |
| 带索引插入 | 吞吐 | 2415 行/s | 2751 行/s | +13.9% |
| 全量检索 | p50 | 329 ms | 325 ms | ±噪声 |
| 全量检索 | QPS | 3.56 | 3.52 | ±噪声 |
| Top-10 检索 | p50 | 8.51 ms | 8.31 ms | ±噪声 |

另外用 `TOKENIZE()` 单独隔离测量分词本身（20000 行文档集）：

| | 基线 | 优化后 | 变化 |
| --- | ---: | ---: | ---: |
| 分词耗时 | 1.81 s | 0.85 s | **-53.3%** |

## 语义一致性

* `regress_*.tsv` 与 `regress_*.tsv.topk` 在基线与优化实例上都**逐字节相同**
  （`md5` 相等）：300 条全量检索与 300 条 Top-10 检索的结果集、行序、BM25 分数
  全部一致。
* 上一实例上出现过的 Top-10 并列行取舍差异来自 OB block-max 剪枝的物理布局，
  用同一数据目录分别加载基线与优化二进制即可复现，与本改动无关；本实例上未出现。
